All Shell Commands

#!/bin/bash
# This script lists all available shell commands in the system

compgen -c

ls -> list directory contents

cd -> change the shell working directory

mkdir -> make directories

rm -> remove files or directories

cp -> copy files and directories

mv -> move (rename) files

touch -> change file timestamps or create empty files

echo -> display a line of text

cat -> concatenate and display file content

grep -> search text using patterns

find -> search for files in a directory hierarchy

chmod -> change file permissions

head -> display the first 5 lines of a file

tail -> display the last 5 lines of a file

pwd -> print working directory

👤 whoami — who am I? Tells you which user you’re logged in as. whoami Useful when: multiple users sudo confusion “wait… am I root?” moments 😵‍💫 🧑‍🚀 sudo — do it as admin Runs a command with root (admin) power. sudo command Example: sudo apt update Only users in sudo group can use it. 👉 Safer than logging in as root. ➕ useradd — create user Adds a new user. sudo useradd username Better (recommended): sudo useradd -m username -m → creates home directory 🔐 passwd — set/change password Sets or changes user password. sudo passwd username Change your own password: passwd 🔄 su — switch user Switch to another user. su username Switch to root: su - Needs target user’s password. 👉 Difference: su → asks root password sudo → asks your password 🧑‍🤝‍🧑 Groups (quick but important) Check user groups groups username Add user to sudo group sudo usermod -aG sudo username (-a = append, don’t mess this up 💀) 🧠 Real-world flow (ADMIN LIFE) sudo useradd -m devuser sudo passwd devuser sudo usermod -aG sudo devuser su - devuser whoami Boom.
